# Contributing

Bu depoya katkıda bulunmak istediğiniz için teşekkür ederiz!

Amacımız, Balıkesir Üniversitesi Bilgisayar Mühendisliği öğrencileri tarafından hazırlanan ders notlarını düzenli ve erişilebilir bir şekilde arşivlemektir.

## Katkı Kuralları

- Paylaşılan notlar size ait olmalı veya paylaşma iznine sahip olmalısınız.
- Telif hakkı bulunan kitap, ücretli kaynak veya öğretim elemanlarına ait materyalleri izin almadan yüklemeyiniz.
- Dosya isimlerini mümkün olduğunca açıklayıcı seçiniz.
- Gereksiz tekrar oluşturmamaya özen gösteriniz.
- Mevcut klasör yapısını koruyunuz.

## Klasör Yapısı

Notlar aşağıdaki yapıya uygun olarak eklenmelidir.

```
1-Sinif/
    1-Donem/
        Programlama-I/
            Ders-Notlari/
            Gecmis-Sinavlar/
```

## Dosya İsimlendirme

Önerilen dosya isimleri:

```
Hafta-01.pdf
Hafta-02.pdf
Vize-Ozeti.pdf
Final-Ozeti.pdf
Lab-01.pdf
```

## Pull Request

Pull Request oluşturmadan önce:

- Doğru klasöre yüklediğinizden emin olun.
- Aynı dosyanın daha güncel bir sürümü olup olmadığını kontrol edin.
- Gerekiyorsa açıklama ekleyin.

## Lisans

Bu depoya katkıda bulunan herkes, eklediği içeriklerin depo ile aynı lisans (**CC BY-NC 4.0**) kapsamında paylaşılmasını kabul etmiş sayılır.

Teşekkür ederiz! 🎓
